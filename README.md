# Drum Kit Game

A fun and interactive drum kit game built with JavaScript, HTML, and CSS. Play your favorite beats by clicking on the drum pads or using your keyboard!

## Features

- **Interactive Drum Pads**: Click on the pads to play different drum sounds.
- **Keyboard Support**: Play the drum sounds using your keyboard keys.
- **Responsive Design**: Works on both desktop and mobile browsers.

## Technologies Used

- HTML
- CSS
- JavaScript
